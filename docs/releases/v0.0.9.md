## LWGF v0.0.9 — Asset Package V1

이번 버전에서는 원본 에셋을 개발 중에는 직접 사용하고, 배포 시에는 자체 바이너리 패키지로 묶을 수 있도록 Asset Package 기능을 추가했습니다.

### ✨ New Features

#### Asset Package
- `assets.pak` 인덱스와 `assets.1`, `assets.2`, ... 데이터 파일로 구성되는 V1 포맷
- 바이너리 단위 분할 및 분할 파일 경계를 넘는 읽기/seek 지원
- 기본 최대 데이터 파일 크기 512 MiB, 게임별 설정 가능
- UTF-8 상대 경로 및 디렉터리 구조 유지
- Package ID, 파일 번호, 크기, CRC32 기반 검증
- V1 무압축, 필요한 에셋만 읽는 방식

#### Asset Packer
- 독립 `LWGFAssetPacker` CLI의 pack / verify 지원
- 임시 staging에 생성하고 전체 CRC 검증 후 결과 교체
- 에셋 추가·수정·삭제 및 이전 분할 파일 정리
- 잘못된 경로와 대소문자 충돌, 관련 없는 파일 덮어쓰기 방지

#### AssetReader & Resource Loading
- 명시적인 Directory / Package 모드와 동일한 논리 에셋 경로
- `AssetReader::ReadAll()`, `AssetStream`의 독립적인 Read / Seek 지원
- Texture2D 및 Font 메모리 로딩 연동
- AudioSystem의 AssetReader 연동, 효과음 PCM 디코딩 및 BGM 스트리밍 유지
- 임시 원본 파일 추출 및 자동 fallback 없음
- 기존 물리 경로 기반 리소스 API 유지

### 🔧 Improvements

- `lwgf_configure_assets()`를 통한 게임 프로젝트별 에셋 루트, 모드 및 분할 크기 설정
- Debug / Release와 독립적인 Directory / Package CMake Preset
- Directory 모드에서 원본 직접 읽기, Package 모드에서 빌드 시 자동 패키징 및 검증
- C++ 코드 변경 없이 에셋만 변경해도 패키징 반영
- 패키징 실패 시 빌드 실패 처리
- 새로운 외부 라이브러리 의존성 없음

### 🧪 Sample & Testing

- SampleGame의 Directory / Package 실행 및 그래픽·오디오 동작 확인
- CTest 9개 통과 (사용자 로컬 Debug)
- Windows CI Debug / Release 빌드, CTest 및 SampleGame 패키징 검증 통과
- 실제 Sample 이미지·폰트·오디오의 원본/패키지 데이터 및 디코딩 결과 비교
- 외부 CMake 프로젝트의 에셋 변경·삭제·실패 처리 및 MSVC 환경 복원 테스트

### Compatibility & Limitations

- Windows / C++20 / CMake / OpenGL / GLFW / GLAD
- 기존 리소스 로딩 API 유지. SampleGame의 기본 Directory 실행은 원본 에셋 루트를 직접 사용합니다.
- Package 빌드는 별도 build tree를 권장하며 매 빌드 전체 재패키징·검증을 수행합니다.
- CRC32는 우발적 손상 검출용이며 암호화, DRM, 원본 추출 방지를 제공하지 않습니다.
- 실제 MazeRunner 적용 및 RAM/CPU/시작 시간/배포 용량 측정은 후속 검증 대상입니다.

---

**Game First, Keep It Lightweight.**

이번 버전은 게임 코드와 원본 에셋의 개발 편의성을 유지하면서 실제 배포에 필요한 최소 패키징 기능을 제공하는 데 중점을 두었습니다.
